# JDBC Employee Management System

## About the Project
The JDBC Employee Management System is a Java-based application that manages employee information using JDBC and a PostgreSQL database. It demonstrates how Java applications connect to a database and perform CRUD operations.

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- PostgreSQL
- Maven
- IntelliJ IDEA

## Features
- Add employee records
- View employee details
- Update employee information
- Delete employee records
- Store and retrieve employee data from PostgreSQL

## Project Structure
- `controller` – Handles application requests
- `dao` – Performs database operations
- `entity` – Contains employee data models
- `dbconnection` – Manages database connectivity

## Prerequisites
- Java JDK 17 or later
- PostgreSQL
- Maven
- IntelliJ IDEA (or another Java IDE)

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure your PostgreSQL database.
4. Update the database connection settings with your local credentials.
5. Run the Java application.

## Learning Outcomes
- Understanding JDBC connectivity
- Performing CRUD operations
- Integrating Java with PostgreSQL
- Organizing Java code using packages
